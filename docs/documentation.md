# Documentation

Standards for structuring and introducing top-level project documentation.

Browse [[index.md]] for the full documentation set.

## Standard Header

Every top-level document except [[index.md]] starts with this header:

```markdown
# <title>

<concise description of scope and purpose -- _inclusive only_>

Browse [[index.md]] for the full documentation set.
```

The description names only the scope and purpose included in the document.
